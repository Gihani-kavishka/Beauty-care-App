# Beauty Care Mobile App

A mobile application developed using React Native (Expo) for managing beauty care services. The app provides features such as user authentication, service browsing, and order management with a clean and user-friendly interface.

## Features
- User Registration & Login
- Browse beauty care services
- Place and manage orders
- Navigation using bottom tabs
- Responsive mobile UI

## Technologies Used
- React Native (Expo)
- JavaScript
- React Navigation
- Node.js (basic backend integration if used)
- Git & GitHub

## Project Structure
- assets/ - Images and static files
- navigation/ - Navigation configuration (BottomTabs)
- screens/ - App screens (Home, Login, Register, Catalog, Order, Welcome)
- App.js - Main entry point
- package.json - Dependencies

## Screens
- Welcome Screen
- Login Screen
- Register Screen
- Home Screen
- Catalog Screen
- Order Screen

## How to Run the Project

### Prerequisites
- Node.js installed
- Expo CLI installed

### Steps
1. Clone the repository:
git clone https://github.com/yourusername/your-repo-name.git

2. Navigate to project folder:
cd BeautyCareApp

3. Install dependencies:
npm install

4. Run the app:
npx expo start

5. Open in:
- Expo Go (Mobile)
- Android Emulator
- Web browser
